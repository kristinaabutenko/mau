# Обчислення значення математичної функції

## Опис
Ця програма обчислює значення складної математичної функції:
> f(x) = sin(19/47) + 30π − 53e * (5 / ((x−8)(x+3))) + 5 * arctan(x−12) − log₁₄(x+9)

Програма перевіряє, чи належить введене користувачем число **x** області визначення функції (тобто чи не призводить воно до ділення на нуль або логарифма від від’ємного числа).  
Якщо значення коректне — обчислює результат з точністю до 8 знаків після коми, інакше виводить повідомлення **"result = undefined"**.

## Використана технологія
Мова програмування: **C++**  
Використані бібліотеки:  
- `<iostream>` — введення/виведення даних  
- `<cmath>` — математичні функції  
- `<numbers>` — математичні константи (π, e)  
- `<iomanip>` — форматування виводу
